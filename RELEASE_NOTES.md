# DearWiki 1.0.4 — Linux

Public Linux desktop installers for **x86-64 / amd64**.

## Included

- Markdown editing with autosave, wiki links, backlinks, search, and a knowledge map.
- Portable vault import/export, Recovery Center, and backup/restore workflows.
- Offline English OCR for attachments and optional user-configured WebDAV/Nextcloud sync.
- No DearWiki account or hosted subscription is required for local use.

## Downloads

- `DearWiki-1.0.4-linux-x86_64.AppImage` — portable app.
- `DearWiki-1.0.4-linux-amd64.deb` — Ubuntu/Debian-based installation.
- `SHA256SUMS` — checksums for the exact release files.

[Installation and update instructions](https://github.com/brannum/DearWiki-downloads/blob/main/INSTALL.md).

Keep a portable backup before upgrading or switching package formats. Snap and direct packages may use separate local profiles. This release does not include ARM64 or 32-bit Linux installers.
