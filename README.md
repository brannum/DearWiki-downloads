# DearWiki for Linux

A local-first Markdown notebook for connected notes, a knowledge map, portable vaults, and recovery.

## Download 1.0.4

These installers are for **64-bit Intel/AMD Linux desktops (x86-64 / amd64)**, not ARM64 or 32-bit systems.

| --- | --- |

Read the [installation and update instructions](INSTALL.md) and [release notes](https://github.com/brannum/DearWiki-downloads/releases/tag/v1.0.4). DearWiki is also available from the [Snap Store](https://snapcraft.io/dearwiki) on the stable channel.

## Your data and account

DearWiki 1.0.4 works locally without a DearWiki account. Optional WebDAV/Nextcloud sync connects to a server you configure. No DearWiki-hosted sync subscription is included.

Export a backup before changing package formats or moving between machines. Snap and direct packages may keep separate profiles; transfer through the app's supported export/import workflow.
